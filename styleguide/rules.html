규칙 색인

이 디자인 시스템이 지키는 규칙을 하나씩 인용할 수 있게 번호를 붙였습니다. 디자인 QA에서 「RM-SURF-02 위반 — 오답 칸에 분홍 면」처럼 번호로 부르면, 개발자도 그의 AI도 이 카드를 열어 근거와 검사 방법을 바로 찾을 수 있어요.

이 장이 규칙의 정본입니다. tools/rules-build.py가 이 카드들을 읽어 styleguide/data/rules.json을 만들고, CLAUDE.md·tools/style-audit.py에 모든 번호가 빠짐없이 인용돼 있는지 대조합니다. 손으로 세 곳을 맞추지 않아요.

읽는 법 번호 · 카드 · 검사

번호는 RM-영역-번호입니다. 영역 열 개 — 색 COL · 칠면 FILL · 학습 화면 면 SURF · 유틸 UTIL · 치수 SIZE · 파일 FILE · 이름 NAME · 이미지 ASSET · 공용 부품 PART · 스크립트 JS. 한 번 붙인 번호는 바꾸지 않습니다. 규칙이 폐기되면 카드를 지우지 않고 「폐기」로 남겨 번호가 다른 뜻으로 재사용되지 않게 합니다.

카드마다 넷을 적습니다 — 지킬 것(한 줄) · 근거(언제 왜 생겼나) · 검사(어느 도구의 어느 줄이 잡나, 또는 눈으로 보는 것) · 예외. 검사 딱지가 기계면 도구가 숫자로 잡고, 눈이면 화면을 보고 판단해야 합니다.

선 굵기 5단 --bw-1 · 1_5 · 2 · 3 · 4는 border·outline·안쪽 테두리 그림자(inset 0 0 0 N)·바깥 링·한쪽 선이 같이 쓴다. 볼록 두께 2단 --depth-2 · 4는 눌리는 버튼 아래로 흐림 없이 내린 그림자(0 N 0 색)의 높이.

근거
그림자 402곳 중 상당수가 사실은 테두리(1.5px 안쪽 선)와 버튼 두께(4px)였다. 같은 뜻의 숫자가 속성마다 흩어져 있었다(2026-10-14, 488곳 변환 · 값 동일 증명).
