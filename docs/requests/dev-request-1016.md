## 1. 요청 16 — 개념 읽기 지문 칸 폭

**지금** 지문 칸(`cockpit-reading__scroll`)의 폭 상한이 760px입니다. 화면 폭 약 1440px부터 지문 칸이 더 넓어지지 않아서, 1600 · 1920 화면에서는 지문과 그림 칸 양옆이 크게 빕니다.

**원하는 모습**
- 브라우저가 넓어지면 지문 칸의 가로 폭만 같이 넓어지고 **880px에서 멈춥니다**(왼쪽 그림 번호 알약 자리 112px 포함). 한 줄이 약 40자입니다(띄어쓰기 뺀 수, 기본 글자 크기 기준).
- 확대(scale)가 아닙니다. 글자 크기 · 줄 간격은 지금 그대로입니다.
- 오른쪽 그림 칸은 지금 크기 그대로입니다. 지문 칸 + 그림 칸 한 쌍이 패널 가운데에 놓이는 방식도 그대로입니다.
- 1280 폭에서는 지문 칸이 원래 상한보다 좁아서(약 600px) 달라지는 것이 없습니다. 880px에 닿는 것은 화면 폭 약 1570px부터입니다.

**확인 링크** [concept/learn-math.html](https://readingmath-v3-proto.vercel.app/concept/learn-math.html) → 브라우저 창 폭을 1280 → 1600 → 1920으로 바꿔 보세요.

**완료 기준** 1600 · 1920 화면에서 지문 칸이 880px이고, 글자 크기와 그림 칸 크기는 1280일 때와 같다.

## 2. 요청 17 — 지문 카운터 위치

**지금** 지문 칸 위의 「지문 ▬ ▭」 카운터가 칸의 왼쪽 끝에 붙어 있습니다. 지문 글은 그림 번호 알약 자리 112px 안쪽에서 시작해서, 카운터와 지문의 왼쪽 선이 어긋납니다.

**원하는 모습**
- 카운터의 왼쪽 선을 **지문 글의 왼쪽 선(칸 안쪽 112px)**에 맞춥니다. 알약 자리는 비워 둡니다.
- 모양과 치수(「지문」 12px 700 · 막대 22×4px · 막대 사이 4px · 지문 첫 줄과의 간격)는 지금 실서비스 그대로 둡니다. 왼쪽 위치만 바꿉니다.
- 카운터는 지문 글과 같이 스크롤됩니다(지금과 같음).
- **지문이 하나면 카운터를 띄우지 않습니다.**

**확인 링크**
- 지문 둘(카운터 있음): [concept/learn-math.html](https://readingmath-v3-proto.vercel.app/concept/learn-math.html) — 프로토타입은 지문 2개 중 첫째로 고정해 보여 줍니다. 넘김 동작은 없습니다.
- 지문 하나(카운터 없음): [concept/learn-sci.html](https://readingmath-v3-proto.vercel.app/concept/learn-sci.html)

**완료 기준** 카운터의 「지」 글자 왼쪽 끝과 지문 첫 글자 왼쪽 끝이 세로로 한 줄에 놓인다. 지문이 하나인 훈련에서는 카운터가 보이지 않는다.

## 3. 요청 18 — 문제 카드 스크롤바

**지금** 개념 다지기 · 서술형 훈련 상단의 문제 카드(`cockpit-problem__body`)는 화면 높이 34%를 넘으면 안에서 스크롤됩니다. 이 스크롤바가 앱 전체 기본값(`body ::-webkit-scrollbar` — 폭 8px · 손잡이 #9DA3B1 · 홈 #F2F3F5)을 그대로 받아서, 진한 파랑 · 보라 카드 안에 밝은 회색 띠가 생깁니다.

**원하는 모습** — 문제 카드 안에서만 바꿉니다. 앱 전체 기본값은 그대로 둡니다.
- 홈(track)은 투명합니다. 띠가 보이지 않습니다.
- 손잡이(thumb)는 흰색 20%(`rgba(255,255,255,.2)`), 끝은 완전히 둥글게.
- 스크롤바 폭은 8px이고, 손잡이 좌우에 2px 투명 테두리를 둬서 보이는 굵기는 4px입니다(`border: 2px solid transparent; background-clip: padding-box`).
- 카드는 라이트 · 다크에서 색이 바뀌지 않는 면이라 스크롤바도 두 테마에서 같은 모습입니다.
- 크롬 · 사파리 밖의 브라우저는 `scrollbar-width: thin; scrollbar-color: rgba(255,255,255,.2) transparent;`로 같은 인상을 냅니다.

```css
.cockpit-problem__body::-webkit-scrollbar { width: 8px; }
.cockpit-problem__body::-webkit-scrollbar-track { background: transparent; }
.cockpit-problem__body::-webkit-scrollbar-thumb {
  background: rgba(255, 255, 255, .2); border-radius: 999px;
  border: 2px solid transparent; background-clip: padding-box;
}
```

**확인 링크** [essay/basics-math.html](https://readingmath-v3-proto.vercel.app/essay/basics-math.html) → 문제 카드 오른쪽 끝. 라이트 · 다크는 머리줄 오른쪽 테마 토글로 바꿔 보세요. 카드가 짧아 스크롤이 조금만 생기면 창 높이를 줄여 보세요.

**완료 기준** 개념 다지기 · 서술형 문제 카드 안에 회색 홈이 보이지 않고, 흰 반투명 손잡이만 보인다. 라이트 · 다크에서 같다.
