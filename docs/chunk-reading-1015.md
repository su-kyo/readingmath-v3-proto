# 끊어읽기 스타일 정리 (2026-10-15)

고학년 분수 지문에서 끊어읽기 장식(지금 구간 면 · 그림 구간 점선/실선 밑줄 · 노란 형광)이 한 줄에 겹쳐 읽기 어려웠다.
실서비스 지문(중3 「삼각비」 · 중2 「빛과 반사」)으로 시안을 만들어 확정하고 화면에 반영했다.
규칙의 정본은 스토리북 `styleguide/rules.html#READ`(`RM-READ-01`~`04`)다. 이 문서는 판단과 개발자 전달 목록만 담는다.

## 반영 범위

- 개념 학습 본문 `concept/learn.html` — 전부
- 개념 요약 모달(같은 화면, `.sseg`) — 지금 구간 평문 · 아무 데나 누르기 · 스페이스바 · 선택 막기 · 행간
- 서술형 다지기 v2 `essay/drill-v2.html` — 문제 읽기 모달 · 풀이 · 순서 맞추기. 위와 같은 네 가지 + 분수 줄 간격
- 개념 정리 `concept/organize.html` — 그림 구간 점선 밑줄과 핵심 문장 강조(색 · 밑줄)를 걷어 평문 한 벌로 (핵심 문장은 사용자 요청)
- 손대지 않음: `essay/drill.html`(가로 안, 킵)

## 확정 값

| 무엇 | 값 |
| --- | --- |
| 안 읽은 곳 | 블러 4.5px + 불투명도 .3 (그대로) |
| 지금 구간 · 읽은 곳 | 평문 — 면 · 색 · 굵기 · 밑줄 없음 |
| 그림이 켜진 구간 | 굵게(`--fw-bold`) + 계열색(라이트 `--th-ink-accent` · 다크 `--th-accent-hi`), 수식은 색만 |
| 그림 번호 알약 | 좌측 폭 112px(알약 100 + 틈 12) · 번호 칸 24px · 알약 높이 30px · 번호 넷 이상이면 알약 안에서 줄 바꿈 |
| 같은 번호 다시 누르기 | 그 그림이 꺼진다 |
| 행간 | 2.1 · 분수가 든 줄은 위아래 `.35em` 더 (서술형 풀이는 원래 2.25라 유지) |
| 스크롤 여유 | 지금 구간 위 120px · 아래 160px (콘솔바 뒤로 숨지 않게) |

## 세션이 정한 것 (2026-10-15 사용자 확정)

- 그림 구간에 닿으면 그 그림이 저절로 켜진다(시안 동작 그대로).
- 그림 영역의 ← → 는 읽은 데까지의 그림만 오간다. 전에는 안 읽은 그림까지 돌았다(뒤 그림에 앞 문제의 답이 보일 수 있다).
- 읽은 그림 구간의 글자를 눌러도 그림이 켜지지 않는다. 지문 누르기는 언제나 「한 칸」이고, 그림은 알약으로만 켠다.
- 빈칸 차례에 지문을 누르거나 스페이스바를 누르면 정답 팝오버가 열린다(닫히지는 않는다). 빈칸 자체를 누르면 열고 닫는다.
- 서술형 본문 그림의 「지금 차례」 테두리도 걷었다. 흐림이 벗겨지는 것만으로 차례를 알린다.
- 문구: 그림 영역 빈 상태 「이미지가 있는 구간에 닿으면 / 여기에 표시돼요」(전: 「용어를 누르면 …」), 서술형 읽기 힌트 「글을 누르면 이어 읽어요」(전: 「구간을 눌러 이어 읽어요」).
- 다크 알약 면은 `--surface-2`.

## 개발자 전달 목록

1. **스페이스바 진행.** `keydown`에서 Space를 잡아 `preventDefault()`(페이지 스크롤 방지). `e.repeat`이면 무시해 꾹 눌러도 한 칸만 간다.
   포커스가 버튼에 남아 있으면 `blur()` 한다(그 버튼이 같이 눌리지 않게). 위에 레이어(요약 · 영상 · 확대 · 연습장 · 입력 팝오버)가 떠 있으면 아래 지문은 넘기지 않는다.
   답할 빈칸이 남은 구간에서는 넘어가지 않는다.
2. **지문 전체 선택 막기.** 지문 컨테이너에 `user-select: none` + `-webkit-tap-highlight-color: transparent`. 지문 아무 데나 누르면 한 칸 간다.
3. **좌측 알약 위치 계산.** 읽은 데까지의 그림 구간마다 첫 줄 상자(`getClientRects()`의 첫 항목)의 세로 가운데를 지문 기준 좌표로 구한다.
   세로 가운데가 8px 안쪽으로 겹치면 같은 줄로 보고 한 알약에 번호를 더한다. 알약 `top = 가운데 − 알약 높이 / 2`.
   줄이 바뀌는 때(창 크기 · 글자 크기 · 웹폰트 도착 · 읽기 진행)마다 다시 계산한다. 모양은 CSS(`.img-tag`), JS는 `top`만 넣는다. 구현은 `scripts/learn-concept.js`의 `renderTags()`.
4. **좁은 화면 위쪽 잘림.** 900px 이하에서 `.content__inner`가 세로 가운데 정렬이라, 지문이 길면 위(그림 영역)가 잘려 스크롤로도 닿지 않았다. `justify-content: flex-start`로 고쳤다.
5. **읽는 곳 따라 스크롤.** 넘길 때 지금 구간을 `scrollIntoView({ block: 'nearest' })`로 보이게 하고, 구간에 `scroll-margin`(위 120 · 아래 160)을 줘 콘솔바 뒤로 숨지 않게 한다.

## 열린 것

- 휴대폰 폭(375px)에서는 좌측 112px 때문에 글 폭이 256px로 좁다. 「좁은 화면에서도 늘 확보」가 확정 사양이라 그대로 뒀다.
- 실서비스 지문(수식 · 한 줄에 그림 여럿)은 프로토타입 개념 학습 화면에 없다. 분수 줄 간격과 한 줄에 여럿 묶기는 시안에서만 눈으로 확인했다.
  알약 안 줄 바꿈은 실제 화면에 가짜 알약을 넣어 확인했다(번호 셋까지 한 줄, 넷부터 둘째 줄이 오른쪽 정렬로 이어진다).
