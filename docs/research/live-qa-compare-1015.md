## A. 요청하기로 한 6개 항목

### 1. 개념 끊어읽기 — 안 됨
- 지금 구간에 파란 면이 깔리고 글자도 파랑입니다(rgb 5,89,184 · 4px 모서리). 프로토는 평문입니다(`RM-READ-01`). 서술형 문제 읽기 창은 보라 면이고 같은 문제입니다.
- 진행: 스페이스바는 됩니다. 지문은 「지금 구간」 글자를 눌러야만 넘어갑니다. 프로토는 지문 아무 데나 누르면 넘어갑니다(`RM-READ-02`).
- 그림 구간: 왼쪽 알약이 없습니다. 그림 구간 글자가 파란 글자와 밑줄로 표시되고(지나간 그림은 점선), 닿으면 그림이 저절로 켜집니다(`RM-READ-03` 미반영).
- 행간 2.0(프로토 2.1), 본문 글자 rgb(31,43,73)(프로토 `--text` rgb 18,30,55).
- 그림 영역 빈 상태 「이미지가 여기에 표시돼요」 「– / –」. 프로토는 「이미지가 있는 구간에 닿으면 / 여기에 표시돼요」 「– / 3」.
- 서술형 읽기 힌트가 옛 문구 「구간을 눌러 이어 읽어요」입니다(프로토 「글을 누르면 이어 읽어요」).

### 2. 빈칸 선지 창 통일 — 안 됨
- 개념·서술형 모두 옛 창입니다. 옅은 파랑 면 · 22px 모서리 · 흰 알약 선지(명조 16px 700) · 원·번호·꼬리 없음.
- 오답은 분홍 테두리의 흐린 칸으로 바뀌고, ✕ 배지와 0.5초 연출이 없습니다. 정답은 바로 채우고 닫힙니다(✓ 배지 없음).
- 서술형 1·3단계는 고르면 채점 없이 채워지고 제출 때 채점됩니다(프로토는 즉시 채점과 오답 토스트).
- 과학 개념 학습에서는 오답 선지를 다시 누를 수 있습니다(비활성이 아님).
- 아래쪽 빈칸에서 열리면 창이 콘솔바 위로 겹칩니다. 서술형에서는 문제 프레임 위로 겹칩니다.

### 3. 타이머 — 다름
- 진행 시간 칩은 있습니다. 제한 시간이 「/ 60분」(12px · 흰 70%)입니다. 프로토는 「/ 60:00」(14px · 흰 80%)입니다.
- 칩 면이 검정 25% 덧칠입니다. 프로토는 `--th-static-deep`입니다(`RM-SURF-05`).
- 넘으면 칩 전체를 빨강으로 칠합니다(rgb 236,16,43, 흰 글자). 프로토 B2는 숫자 빨강 300과 테두리 500입니다. 실제로 60분을 기다리지는 않았고, 스타일 규칙과 클래스를 잠깐 붙여서 확인했습니다.
- 정지(스텝 결과)는 칩 전체를 62%로 흐리게만 합니다. 일시정지 표시 ❙❙가 없습니다. 해설 화면에서는 타이머가 아예 사라집니다(프로토는 정지 상태로 보임).
- **새로 안 것**: 과학 유형은 제한이 「/ 30분」입니다(5문제). 제한 시간은 콘텐츠마다 다릅니다. 프로토의 「60:00」은 예시 값이라고 요청문에 적어야 합니다.
- 개발자가 넣은 것: 타이머에 마우스를 올리거나 포커스하면 말풍선 「60분 안에 문제를 모두 풀어보세요!」가 뜹니다.

### 4. 유형 계산기 색 — 안 됨
- 몸체가 민트 rgb(229,253,248)이고, 표시창 글자는 틸, 기능키(⌫ C −)는 민트 면에 틸 글자입니다.
- 프로토는 계열과 상관없는 회색 한 벌(`--kp-*`)입니다. 몸체 rgb(228,236,251), 기능키 rgb(240,245,254)에 rgb(58,70,106) 글자, 표시창 글자 rgb(240,245,254)입니다. 확인 키만 계열색이고, 확인 키는 같습니다.
- 개념 계산기는 확인 키가 파랑이고 몸체는 측정하지 못했습니다.
- 물리 키보드 입력이 안 됩니다(프로토는 됨). 같은 칸을 다시 누르면 닫힙니다.

### 5. 유형 오답 해설 박스 — 안 됨
- 탁한 회보라 면 rgb(228,224,227)에 안쪽 1.5px 주황 40% 선, 16px 모서리입니다. 머리는 「💡 오답 해설」 주황 14px 800입니다.
- 프로토(오늘 정함)는 옅은 틸 면 `--th-tint`(틸 8%)이고 선과 띠가 없으며 12px 모서리입니다. 머리는 「💡 해설」입니다. 머리 이름(「오답 해설」 vs 「해설」)은 사용자 판단이 필요합니다.

### 6. 연습장 연출 — 안 됨
- 「연습장」을 누르면 같은 콘솔바 안에서 버튼이 주황 「✕ 연습장 닫기」로 바뀌고 도구가 옆에 펼쳐집니다. 바가 내려가고 새 바가 올라오는 연출은 없습니다.
- 딤과 문제 영역 구멍은 있습니다(프로토와 같은 구조).
- 도구 버튼은 진한 틸 칠에 흰 아이콘입니다. 지우개와 전체 지우기는 Font Awesome 아이콘(eraser · trash-can)이고, 경로를 받아 두었습니다 → `dev-scratch-icons.md`.
- 순서 맞추기 중에는 콘솔바에서 「연습장」이 사라집니다.

## B. 디자인 시스템과 어긋난 곳 (요청 후보)

1. **정오답 칸에 면을 칠함** (`RM-SURF-02`). 객관식 오답은 분홍 면, 정답 공개는 연두 면, 빈칸 채점은 초록 12%와 빨강 10% 면입니다. 개념 다지기·기초 연산·유형 해설·서술형 해설 모두 같습니다. 프로토는 흰 면에 2px 선, 배지, 글자로만 표시합니다.
2. **보기 박스에 면을 칠함** (`RM-SURF-04`). 과학 개념 확인하기와 유형에서 보기 박스가 n-100으로 칠해져 있고 선이 없습니다. 선지 선은 n-100이라 보기보다 연합니다. 유형(틸 화면)에서는 파란 기운 면이 따로 놉니다.
3. **빈칸 자리표시 「1-1」「2-1」**. 회색 번호가 박힌 파랑 15% 면과 점선입니다. 프로토에는 번호가 없습니다(콘텐츠 데이터인지 확인 필요).
4. **결과 화면 콘솔바 구성**. 「연습장」이 빠졌고 「홈으로」가 오른쪽으로 갔습니다. 유형·서술형 결과에는 「유형 도전」이 추가됐고, 서술형 결과에 「유형 도전」이 있는 것은 의도인지 확인이 필요합니다. 스텝 결과의 진행 점 「1/3」도 없습니다.
5. **브레드크럼 끝이 단계에 따라 안 바뀜**. 개념 다지기·정리에서도 「개념 학습」이고, 유형 해설에서도 「1차 유형 문제」입니다(프로토 「개념 다지기」 「해설 보기」).
6. **CTA 위치**. 「채점하기」 「다음 문제」를 본문 가운데에서 콘솔바 오른쪽으로 옮기고 안내 알약과 짝을 지었습니다. 디자인이 바뀐 것이고, C절과 같이 판단할 일입니다.
7. **창 위치**. 키패드와 선지 창이 위아래 가장자리에서 헤더나 콘솔바와 겹칩니다.
8. **낮은 정답률 계기판**. 7~10%일 때 아크 시작 끝이 깃발 모양 조각처럼 보입니다(눈으로 확인 필요).
9. **기초 연산 결과는 개발자가 새로 만든 구성**입니다. 문항 번호 타일 1~14로 되어 있고, 프로토는 공용 스텝 결과(행 막대)입니다. 유형 스텝 결과와 같은 문법이라 자연스럽습니다.

## C. 개발자가 넣은 안내 문구 · 동작 (3단계 재료)

**콘솔바 가운데 안내 알약 `cockpit-guide`.** 다크 알약(rgb 15,25,48)에 깜빡이는 8px 램프와 14px 700 글자입니다. 램프·글자 색은 기본 파랑, 정답 초록, 오답 빨강입니다.
- 「글을 눌러 이어 읽어 주세요!」 (끊어읽기 시작 · 서술형 빈칸 맞추기 읽는 중)
- 「다 읽었어요! 내용 요약해보기 버튼을 눌러 주세요!」 (+ 요약 버튼 주황 활성 · 주의 애니메이션)
- 「답안을 입력해 주세요!」 (미입력 · 빈칸 차례 — 객관식에서도 같은 문구)
- 「모든 답안을 입력해 주세요!」 (입력칸이 여러 개)
- 「정답이에요!」 (초록) / 「오답을 눌러 정답을 확인해 보세요!」 (빨강 · 해설에서는 파랑)
- 「위쪽 문항 표시나 화살표를 눌러 이동할 수 있어요!」 (해설)
- 「순서 맞추기 문제로 이동해 주세요!」 / 「블록을 눌러 넣거나 알맞은 자리에 끌어다 놓아 주세요!」 (서술형 2단계)

**그 밖의 문구·동작**
- 타이머 말풍선 「60분 안에 문제를 모두 풀어보세요!」 (제한 값을 따라 바뀜)
- 해설 종료 확인 창 「해설 보기를 종료하실 거예요?」 (취소 / 확인)
- 단계 시작 확인 창 「학습을 시작하시겠어요?」(취소 / 학습하기) · 「학습을 이어서 진행하시겠어요?」(취소 / 이어하기) — 옛 흰 모달
- 훈련 완료 축하 화면 「○○ 훈련을 완료했어요!」 + 「자세히 보기 →」(+ 「유형 도전 →」)
- 훈련 결과 칩 「● 기준 시간 내」 (프로토는 넘었을 때 「시간 초과 감점」만)
- 다지기·기초 연산: 오답 칸을 눌러야 정답이 공개되고, 그 뒤에 「다음」이 켜집니다(프로토는 채점 즉시 정답도 표시).
- 개념 다지기 객관식 선지 등장 연출(흐림 → 또렷)
- 문제 프레임이 스크롤하면 접힙니다(칩 줄만 남음).

프로토에 이미 비슷한 것이 있습니다. 서술형 해설 2장의 본문 안내 「오답을 눌러 정답을 확인해보세요!」(`.review-hint`)입니다.

## D. 3단계 목록 (탐방 뒤 결정하기로 한 것)

- **결과 계기판 색**: 테스트 서버는 개념 스텝 결과와 훈련 결과 모두 **cyan-400(#14BAE1)**입니다. 프로토 개념 훈련 결과가 cyan-300과 400이 섞여 있으니 → 프로토를 cyan-400으로 맞추기를 추천합니다(요청문 항목 아님).
- **훈련 결과 토스트 색**: 테스트 서버에서는 해당 토스트가 뜨는 장면이 없었습니다(오답노트 버튼이 실제로 이동). → 이번 범위에서 제외를 추천합니다.
- **서술형 프레임 위 글자 투명도 85~94%**: 테스트 서버는 이 값을 따로 쓰지 않습니다(흰 글자). → 프로토만 한 값으로 정리하고 요청에서는 빼기를 추천합니다.

## E. 프로토 쪽 잔손질 (탐방 중 발견)
- `concept/drill.html` 탭 제목이 「기초 연산」입니다 → 「개념 다지기」로.
- 훈련 결과 코멘트 「88점 입니다」 띄어쓰기 → 「88점입니다」(개발자는 붙여 씀).
- 타이머 「60:00」이 고정값처럼 보입니다 → 요청문에 「콘텐츠의 제한 시간」이라고 명시.

## F. 개발자에게 확인할 것
- 빈칸 번호 「1-1」이 콘텐츠 데이터인지 화면이 붙인 것인지
- 서술형 결과의 「유형 도전」 버튼이 의도인지
- 연습장 아이콘(Font Awesome Regular eraser) 라이선스 — 프로토 공개 배포에 같은 경로를 써도 되는지
- 서술형 2단계 해설이 「첫 시도 답」을 기록하는 것이 의도인지(재시도로 맞혀도 오답 표시)
