# 빈칸 선지 창 통일 (2026-10-15)

빈칸을 누르면 뜨는 「선지 고르기」 창이 개념(`.answer-pop`)과 서술형(`.qpop` + `.pop-opt`)에서 모양 · 열림 동작 · 오답 처리 · 다크 처리가 모두 달랐다.
시안 넷을 비교해 한 부품으로 정하고 개념 학습 1장 · 서술형 6장에 반영했다.
규칙의 정본은 스토리북 `styleguide/rules.html#RM-PART-06`, 견본은 `styleguide/components.html#input`의 「빈칸 선지 창」이다. 이 문서는 판단과 개발자 전달 목록만 담는다.

## 반영 범위

- 개념 학습 `concept/learn.html` — 끊어읽기 빈칸 (즉시 채점)
- 서술형 훈련 `essay/drill-v2.html` · `essay/drill.html`(가로 킵안) — 즉시 채점
- 서술형 `essay/basics-v2.html` · `basics.html`(킵) · `advanced.html` · `report.html` — 채점 없이 고른 값을 바로 넣는다
- 유형: 실서비스 유형 훈련에 빈칸 객관식이 없다(사용자 확인). 대상 아님
- 손대지 않음: 서술형 주관식 키패드 창(`.qpop`) — 계산기와 같은 정적 하드웨어(`RM-PART-03`). 개념 요약 모달의 선지 영역(`#summaryOptions`) — 창이 아니라 모달 안에 붙박인 목록

## 판단

- **축 두 개로 시안 넷을 갈랐다.** 물건의 성격(테마를 따라 뒤집히는 카드 / 늘 밝은 계기 부품) × 선지 모양(점 달린 목록 / 칸마다 선을 두른 버튼).
- **「카드 · 목록」(A)을 골랐다.** 세션 추천은 C(부품 · 목록, 키패드 창과 한 가족)였으나 사용자가 A를 골랐다.
  그래서 서술형에서는 객관식 창(카드, 다크에서 뒤집힘)과 주관식 키패드 창(늘 밝음)이 서로 다른 물건이 된다.
- **왼쪽 원이 정오답 배지가 된다.** 오답은 빨강 500 원에 흰 ✕, 정답은 초록 500 원에 흰 ✓ (`RM-FILL-05`, 결과 화면 진행 원과 같은 아이콘). 사용자 요청.
- **오답 뒤 비활성은 회색 ✕로 남는다.** 빨강은 누른 순간(0.5초)에만 쓴다. 사용자 요청.
- **동작은 두 계열 공통으로 정했다.** 고른 오답은 다시 못 고른다(전: 개념은 0.5초 뒤 원래대로). 정답은 초록 0.5초 뒤 닫힌다(전: 서술형은 바로 닫힘).
- **안내 문구 「알맞은 말을 고르세요」를 없앴다.** 숫자 · 수식 선지에 「말」이 맞지 않고, 빈칸을 누른 순간 할 일이 분명하다.

## 세션이 정한 것 (사용자 확인 전)

- 선지 글자는 두 계열 모두 고딕 16px 600. 서술형은 전에 명조 16px 700이었다. 빈칸에 채워지는 답은 지금처럼 각 화면의 본문 서체를 따른다.
- 수식 선지는 글자의 1.15배(KaTeX). 16px 그대로 두면 근의 공식의 b² · 루트 안 글자가 너무 작았다.
- 원 18px → 20px (배지 아이콘 13px이 들어갈 자리).
- 창 가장자리 선: 라이트 `--border`(나누는 것) · 다크 `--border-strong`(다크에서 `--border`는 거의 안 보인다). 면: 라이트 `--surface-1` · 다크 `--surface-2`.
- 빈칸과 창 사이 12px(개념 값. 서술형은 9px였다). 화면 가장자리 여백 8px. 꼬리는 창 모서리에서 22px 안쪽까지만 간다.
- 스크롤하면 창이 빈칸을 따라간다(전: 서술형은 닫힘). 빈칸이 화면 밖으로 나가면 닫는다. 위쪽 칸이 접히며 빈칸이 밀리는 것도 따라간다(매 프레임 위치 확인).
- 바깥을 누르면 닫힌다. 개념에서 빈칸 차례에 지문을 누르면 닫혔다가 바로 다시 열려, 전처럼 「열린 채」로 보인다.
- 서술형 훈련의 오답 토스트(「오답이에요. 다시 골라 볼까요?」)는 그대로 둔다. 개념에는 토스트가 없다(빈칸이 같이 흔들린다).
- 층위는 `--z-float`(팝오버 자리). 서술형 옛 창은 `--z-toast`였다.

## 개발자 전달 목록

1. **부품 하나.** 모양 `styles/components.css`의 `.bpop`, 동작 `scripts/blank-pop.js`(`window.RMBlankPop`). 창 요소는 처음 열 때 `body` 끝에 하나 만들어 재사용한다.
   ```js
   RMBlankPop.open(빈칸요소, {
     choices: ['성질', '무게', { tex: '\\dfrac{1}{2}', val: '1/2' }],
     answer: '성질',                       // 없으면 채점하지 않는다
     onPick: function (val, ok) {},        // 누른 순간 (채점할 때만)
     onDone: function (val) {},            // 정답 0.5초 뒤 닫힌 다음 / 채점 없음이면 바로
     onClose: function () {}               // 어떻게 닫히든
   });
   ```
2. **상태는 선지마다 넷.** 기본 · `.is-wrong`(0.5초, 흔들림 0.4초) → `.is-dead`(이후 계속) · `.is-correct`(0.5초). 호버는 CSS `:hover`.
   정답 0.5초 동안은 다른 선지를 누를 수 없다. 그 사이에 창이 닫혀도(바깥 누름) `onDone`은 불린다.
3. **비활성은 빈칸마다 기억한다.** 같은 빈칸을 닫았다 다시 열어도 고른 오답은 비활성 그대로다. 프로토타입은 빈칸 요소에 붙여 두지만(`_bpopDead`), 실서비스는 문항 상태에 저장해야 한다.
4. **열림 위치 규칙.** 빈칸 아래 12px. `아래 공간 < 창 높이 + 12 + 8`이고 위에 공간이 있으면 위로 뒤집고(`.is-up`) 꼬리를 아래로 단다.
   가로는 빈칸 가운데에 맞추되 화면 가장자리 8px 안으로 민다. 꼬리 가로 위치는 `--bpop-caret-x`(창 왼쪽 기준 px).
5. **닫히는 때.** 바깥 누름(캡처 단계에서 먼저 닫는다) · Esc · 정답 0.5초 뒤 · 빈칸이 화면 밖으로 나감. 빈칸 자신을 누르는 것은 화면이 정한다(개념 · 서술형 기초는 토글).
6. **수식 선지.** KaTeX로 그린다(`{ tex }`). 채점 값은 `val`로 따로 준다(수식 문자열로 비교하지 않게). 프로토타입 화면에는 아직 수식 선지가 없다 — 시안에서 분수 · 근의 공식 · 삼각비로만 확인했다.
7. **다크.** 창은 테마를 따라 뒤집히고 배지(500 채움 + 흰 아이콘)는 안 뒤집힌다(`RM-FILL-06`).

## 열린 것

- 채점 없는 화면에서 이미 채운 빈칸을 다시 열 때 「지금 들어 있는 값」 표시가 없다. 필요하면 상태를 하나 더 둔다(예: 원만 채운 기본색).
- 키보드로 선지 고르기(숫자키 1~5)는 없다. 태블릿 기준이라 미뤘다.
- 시험 풀이의 정오답 칸(`exam-solve.css`)은 이번 범위가 아니다(`CLAUDE.md` ②-4 「알려진 미적용」).
