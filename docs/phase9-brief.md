### 이번 회차의 진행 방식 (사용자가 정함)

**유형 훈련 안의 4개 스텝은 활동이 서로 똑같다.** 그래서 4번을 다 굴리지 않는다.

1. **사용자가 스텝 3개를 직접 푼다.** 세션은 그동안 아무것도 조작하지 않는다
   (동시에 클릭하면 서로 방해한다). 사용자가 "됐다"고 할 때까지 기다린다
2. **세션이 남은 스텝 1개를 진행하며 캡쳐한다**
3. **스텝 결과**와 **훈련 결과**를 열어 확인하고 캡쳐한다

### 캡쳐 방법 (9-1에서 확립 — 그대로 쓴다)

- 조작은 **Claude in Chrome 확장**으로 한다. 확장은 이미 설치·로그인돼 있다.
  연결이 안 되면 사용자에게 크롬 사이드 패널을 한 번 열어 달라고 요청한다
- 촬영은 **`~/.claude/venv-quartz/shot.sh <파일이름>`** 한 줄.
  크롬을 앞으로 내고, 창 위치를 읽어 **페이지 영역만**(탭바·주소창·북마크바 제외)
  잘라 `~/Documents/_source/RM/live-capture/`에 저장한다
- **함정**: 확장이 화면을 조작한 직후엔 크롬 위에 「'Claude'에서 이 브라우저에 대한
  디버깅을 시작함」 안내 바와 주황 테두리가 뜬다. 스크립트가 **14초 기다린 뒤** 찍는 이유다.
  급하다고 줄이지 말 것
- 찍은 뒤 반드시 검사한다:
  `~/.claude/venv-quartz/bin/python ~/.claude/venv-quartz/check.py "$HOME/Documents/_source/RM/live-capture/*.png"`
  → `OK`가 아니면 다시 찍는다
- **비율은 16:9가 아니다.** 뷰포트 그대로 2940×1450(2.03:1). 창을 좁히면 좌우가 잘려
  로고와 「행성 메인으로」가 날아가서 사용자가 그대로 두기로 했다. 장표에서 여백을 준다
- 파일명 `live-math-type-<화면>-NN.png` (9-1은 `live-math-concept-*`·`live-math-basic-*`·
  `live-math-result-*`로 08번까지 썼다. **09부터 이어서 번호를 매긴다**)

### 조작 요령 (9-1에서 배운 것)

- 확장의 `computer` 스크린샷 좌표계는 **1470×669**이고 페이지 CSS 픽셀과 같다.
  화면을 찍어 보고 그 좌표로 클릭하면 된다
- 키패드는 **누른 답 칸 바로 아래**에 펼쳐진다. 칸이 바뀌면 키 위치도 바뀌므로,
  칸을 누른 뒤 스크린샷을 한 번 찍어 좌표를 다시 잡는다
- `javascript_tool`로 키패드 버튼을 누르는 건 **안 먹는다**(Vue 핸들러). 좌표 클릭만 된다.
  다만 지문 구간 넘기기(`.frame__body.click()`)는 JS로도 된다
- `browser_batch`로 여러 클릭을 한 번에 보내면 빠르지만, 패널이 스크롤되면 좌표가
  어긋난다. **3~4수 앞까지만 묶고 확인**하는 편이 결국 빠르다

### 무엇을 볼 것인가

콘텐츠가 아니라 **UX 사용성과 UI 미감**이다. 9-1에서 이미 확인된 것
(수식 이미지 · 오답 색 3종 · 키패드 이동 · 테마 불일치 · 비활성 30% 등)은
**유형 훈련에서도 같은지만 짧게 확인**하고, 아래처럼 **유형 훈련에만 있는 것**에 집중한다.

- **4개 스텝을 어떻게 안내하는가** — 스텝 사이 이동, 지금 몇 번째인지, 남은 게 몇인지
- 문제 유형이 개념 훈련과 어떻게 다른가 (보기 제시형·다중 입력형이 나오는지)
- **스텝 결과** 화면 — 개념 훈련의 스텝 결과와 같은 양식인가, 등급 기준은 같은가
- **훈련 결과** 화면 — 4스텝이 표에서 어떻게 집계되는가, 진단·처방 문장이 유형용으로
  달라지는가
- 한 문제를 푸는 조작 수, 상태 표현, 시각 위계, 마이크로카피

그리고 반대 방향도 본다 — **현안에 있는데 우리에게 없는 장치.**
9-1에서는 진단·처방 문장, 오답 확인 잠금, 분수 구조 입력칸 셋을 찾았다.

**중요**: 발견마다 **우리 프로토타입에 대응 화면이 있는지** 같이 메모한다
(유형 훈련은 `type/train.html`, 결과는 `shared/step-result.html`·`training-result.html`).
대응이 없으면 없다고 적는다 — 그 사실이 다음 단계의 입력값이다.
