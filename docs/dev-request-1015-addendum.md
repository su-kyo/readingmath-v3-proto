## 1. 요청 10 — 창 위치 (11절 교체본)

**지금**
- 아래쪽 빈칸에서 연 선지 창과 오른쪽 칸에서 연 키패드가 콘솔바 위로 겹칩니다.
- 위쪽 빈칸에서 연 키패드가 머리줄(브레드크럼) 위로 올라갑니다.
- 서술형 1단계 선지 창이 문제 프레임을 덮습니다.

**원하는 모습** — 키패드 · 빈칸 선지 창의 열림 위치는 이 절이 정본입니다.
- 창은 **머리줄 아래 ~ 콘솔바 위 영역 안, 그 가장자리에서 8px 안쪽**에서만 열립니다.
- 빈칸(입력칸) 아래 12px에 여는 것이 기본입니다. 아래 공간이 모자라면 위로 뒤집습니다(꼬리도 아래로). 위아래 모두 모자라면 문제 영역을 스크롤해 빈칸을 보이게 옮긴 뒤 엽니다.
- 스크롤로도 자리가 안 나면(문제 영역이 스크롤되지 않는 화면의 키패드) 키패드만 입력칸 옆에 엽니다. 오른쪽이 우선이고, 모자라면 왼쪽입니다. 꼬리가 있는 선지 창은 옆으로 열지 않습니다.
- 분수 칸(분자 · 분모)의 키패드는 처음부터 입력칸 옆에 엽니다. 위아래로 열면 짝 칸을 덮습니다. 오른쪽이 우선이고, 모자라면 왼쪽입니다.
- 서술형처럼 문제 카드가 스크롤 영역 위에 붙어 있으면, 빈칸은 카드 아래에서 보여야 합니다. 창도 카드 아래가 우선입니다. 카드 아래 공간이 창보다 작을 때만 창이 카드 위로 올라가고, 그때도 머리줄은 넘지 않습니다. 카드를 펼쳐 둔 채 키패드를 열면 대개 이 경우입니다.
- 빈칸이 영역 밖으로 나가면(머리줄 · 문제 카드 뒤로 숨거나 콘솔바 아래로 내려가면) 창을 닫습니다. 스크롤하는 동안은 창이 빈칸을 따라갑니다.

**확인 링크**
- 개념 학습, 지문 맨 아래 빈칸(위로 열림): [concept/learn.html?debug=1&do=영상 닫기|빈칸 오답](https://readingmath-v3-proto.vercel.app/concept/learn.html?debug=1&do=%EC%98%81%EC%83%81%20%EB%8B%AB%EA%B8%B0%7C%EB%B9%88%EC%B9%B8%20%EC%98%A4%EB%8B%B5)
- 개념 다지기 키패드(입력칸 아래 12px): [concept/drill.html?debug=1&do=키패드 열기](https://readingmath-v3-proto.vercel.app/concept/drill.html?debug=1&do=%ED%82%A4%ED%8C%A8%EB%93%9C%20%EC%97%B4%EA%B8%B0)
- 서술형 1단계(카드 아래에 열림): [essay/basics-v2.html](https://readingmath-v3-proto.vercel.app/essay/basics-v2.html) → 풀이를 아래로 내려 콘솔바 바로 위 빈칸 누르기. 문제 카드를 접고 펴며 키패드 칸도 눌러 보기
- 분수 칸(옆으로 열림): [concept/basic-ops.html?debug=1](https://readingmath-v3-proto.vercel.app/concept/basic-ops.html?debug=1) → 검수 패널 「정답 처리」와 콘솔바 「다음 문제」로 10번까지 넘긴 뒤 분자 칸 누르기

**완료 기준** 어떤 빈칸에서 열어도 창이 머리줄 · 콘솔바와 겹치지 않고 빈칸을 가리지 않는다. 문제 카드 뒤에 숨은 빈칸에 창이 열리지 않는다.

## 2. 요청 12 — 개념 학습 「글자」 버튼 (13절 교체본)

**지금** 개념 학습 콘솔바에 「연습장」(과학은 「개념 영상 보기」도)만 있습니다.

**원하는 모습** 콘솔바 왼쪽 묶음 「연습장」 옆에 「글자」 버튼(글자 크기 조절)을 둡니다. 누르면 버튼 위에 말풍선이 뜹니다. 긴 지문을 태블릿으로 읽는 화면이라 접근성 기능으로 넣고 싶습니다.
- **단계**: 기본 100% · 크게 115% · 더 크게 130%. 지금 지문 글자 크기에 곱합니다(1280 폭에서 19.2 · 22.1 · 25px).
- **커지는 것**: 지문만 커집니다. 행간은 2.1 비율 그대로이고, 그림 번호 알약은 바뀐 줄 위치를 따라갑니다. 오른쪽 그림 칸 · 개념 요약 창 · 머리줄 · 콘솔바는 그대로입니다.
- **말풍선**: 면은 계열색 600(개념 #0559B8)이고 라이트 · 다크에서 같은 색입니다. 글자 · 아이콘은 흰색이고 대비는 6.7:1입니다. 모서리 16px, 안쪽 여백 8px, 그림자 `0 18px 40px -14px` 남색 40% + `0 3px 10px` 남색 12%. 꼬리 12px가 버튼 가운데를 가리킵니다. 말풍선 아래 끝과 버튼 사이는 26px입니다(꼬리가 콘솔바 트레이 윗선에 묻히지 않게). 열고 닫힐 때 0.14초 페이드 + 4px 이동.
- **내용**: `[가− · 점 셋 · 가+]`. 「가−」는 명조 16px 700, 「가+」는 22px 700이고 누르는 영역은 각각 48×48px입니다. 점은 10px 원(흰 테두리 2px)이고 지금 단계만 흰색으로 채웁니다. 점을 누르면 그 단계로 바로 갑니다. 끝 단계에서는 −나 +를 35%로 흐리게 하고 누를 수 없게 합니다. 마우스를 올리면 흰 16% 면.
- **닫힘**: 버튼을 다시 누름 · 바깥 누름 · Esc. 단계를 바꿔도 말풍선은 열린 채입니다.
- **기억**: 고른 단계는 다음 개념 학습에도 유지합니다.

**확인 링크** [concept/learn.html?debug=1&do=영상 닫기](https://readingmath-v3-proto.vercel.app/concept/learn.html?debug=1&do=%EC%98%81%EC%83%81%20%EB%8B%AB%EA%B8%B0) → 콘솔바 「글자」 누르기. 라이트 · 다크는 머리줄 오른쪽 테마 토글로 바꿔 보세요.

**완료 기준** 세 단계로 지문 글자가 커지고 그림 번호 알약이 줄을 따라간다. 말풍선이 라이트 · 다크에서 같은 파란색이다. 다음 개념 학습에서도 고른 크기가 남아 있다.

**규칙** `RM-FILL-01` · `RM-FILL-06`

## 3. 요청 16 — 문제 카드 스크롤바 (새로)

**지금** 개념 다지기 · 서술형 훈련 상단의 문제 카드(`cockpit-problem__body`)는 화면 높이 34%를 넘으면 안에서 스크롤됩니다. 이 스크롤바가 앱 전체 기본값(`body ::-webkit-scrollbar` — 폭 8px · 손잡이 #9DA3B1 · 홈 #F2F3F5)을 그대로 받아서, 진한 파랑 · 보라 카드 안에 밝은 회색 띠가 생깁니다.

**원하는 모습** — 문제 카드 안에서만 바꿉니다. 앱 전체 기본값은 그대로 둡니다.
- 홈(track)은 투명합니다. 띠가 보이지 않습니다.
- 손잡이(thumb)는 흰색 20%(`rgba(255,255,255,.2)`), 끝은 완전히 둥글게.
- 스크롤바 폭은 8px이고, 손잡이 좌우에 2px 투명 테두리를 둬서 보이는 굵기는 4px입니다(`border: 2px solid transparent; background-clip: padding-box`).
- 카드는 라이트 · 다크에서 색이 바뀌지 않는 면이라 스크롤바도 두 테마에서 같은 모습입니다.
- 크롬 · 사파리 밖의 브라우저는 `scrollbar-width: thin; scrollbar-color: rgba(255,255,255,.2) transparent;`로 같은 인상을 냅니다.

```css
.cockpit-problem__body::-webkit-scrollbar { width: 8px; }
.cockpit-problem__body::-webkit-scrollbar-track { background: transparent; }
.cockpit-problem__body::-webkit-scrollbar-thumb {
  background: rgba(255, 255, 255, .2); border-radius: 999px;
  border: 2px solid transparent; background-clip: padding-box;
}
```

**확인 링크** [essay/basics-math.html](https://readingmath-v3-proto.vercel.app/essay/basics-math.html) → 문제 카드 오른쪽 끝. 라이트 · 다크는 머리줄 오른쪽 테마 토글로 바꿔 보세요. 카드가 짧아 스크롤이 조금만 생기면 창 높이를 줄여 보세요.

**완료 기준** 개념 다지기 · 서술형 문제 카드 안에 회색 홈이 보이지 않고, 흰 반투명 손잡이만 보인다. 라이트 · 다크에서 같다.

**규칙** `RM-FILL-06`
