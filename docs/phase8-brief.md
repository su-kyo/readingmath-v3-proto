## 1. 현안 진단 (2026-08-24 탐방 결과)

현안 페이지 구성: 주간 선택(달력에서 종료일 선택 → 적용하기) / 주간 성취도 KPI 6종 /
4주간 성취도 그래프(이중축) + 같은 내용의 표 / 학습내용별 학습기록(소단원 카드 안에
ROUND 행, 훈련 3칸) / 학습일시별 학습기록 / 도움말 정적 박스 3줄.

확인된 동작 사실:

- **라운드는 훈련(개념·유형·서술형)별로 독립 진행**된다. 한 훈련의 라운드 N을 마쳐야
  그 훈련의 라운드 N+1이 열린다. **최대 3라운드.** 서술형은 잠김이 아니라 언제든 시작
  가능("학습을 시작할까요?" 모달).
- 라운드 행 오른쪽 회색 [···]는 **소단원 종합 결과** 자리 — 그 라운드의 세 훈련을 모두
  완료해야 열린다(도움말 3번 줄의 규칙).
- 완료 = 별+점수, 진행중 = 「학습중」(클릭 → 이어서 진행할까요 모달), 미시작 =
  「학습하기」(클릭 → 시작할까요 모달). 완료 클릭 → 결과 모달(완료 일시 · 세부 활동별
  정답/문제/정답률 표 · 닫기/복습하기).
- 등급은 별 1개의 색 4종: S 무지개(Excellent!) · A 노랑(Great!) · B 하늘(Good!) ·
  C 갈색(Nice Try!).
- 두 목록(내용별·일시별)은 **행 단위가 같다**(훈련 1회). 일시별에서 점수를 눌러도 같은
  결과 모달이 뜬다.
- 주간은 "종료일 포함 지난 7일" 롤링 방식. 페이지는 **현재 선택된 학기와 무관하게**
  기록을 보여준다(설정은 초3-2인데 초6-1 기록이 표시됨).
- 오답노트는 별도 메뉴(유형·서술형 버전만 존재). 이 페이지와는 분리돼 있다 —
  Phase 8 범위 아님, 존재만 인지.

### 문제 다섯 (우리 안이 답해야 할 것)

1. **성취도 = 정답률.** 이름이 둘인데 숫자가 하나(83%/83). 정의는 어디에도 없다.
2. **그래프 = 표.** 4주 이중축 그래프 바로 아래 같은 숫자의 표. 0인 주에도 라벨이 붙는다.
3. **잠김의 이유가 화면에 없다.** 라운드 N+1 부재, 회색 소단원 결과 — 규칙은 화면 반대편
   도움말 목록에만 있다.
4. **'학습내용별'이 주간 필터에 갇힌다.** 단원 기준으로 묶어 놓고 그 단원의 전체 진행은
   안 보인다. "이 단원 어디까지 했지?"에 답을 못 한다.
5. **라운드 반복의 성장이 안 보인다.** R1 개념 83, R2 개념 83 — 같은 별이 두 개.
   실제로는 개념 학습 파트가 50%→75%로 올랐는데, 모달을 두 번 열어 암산해야 안다.
   '다시 시도'가 이 서비스의 핵심 행동인데 그 보상이 화면에 없다.

부수 발견: 빈 주를 고르면 KPI·목록이 제목까지 통째로 사라져 고장처럼 보인다 ·
그래프 축이 0~5로 재조정돼 의미 없는 눈금이 생긴다 · 다른 주를 골라도 표 첫 행이
「이번주」다 · 태블릿 세로(768px)에서 KPI 숫자가 카드 밖으로 넘치고 라운드 줄이 잘린다.

## 2. 페이지 정체 (확정 제안)

**회고와 성장 확인이 1순위, 학습 진입은 보조.**
"다음에 뭘 할지"는 행성 홈과 커리큘럼이 이미 맡고 있다(홈 명판의 진행 세그먼트,
커리큘럼의 소단원 트리). 학습 기록까지 진입점을 겸하면 같은 정보를 세 화면이 다르게
말하게 된다. 다만 현안처럼 **진행중 「이어하기」와 다음 라운드 「다시 하기」는 남긴다** —
기록을 보다가 "마저 해야지"가 되는 자연스러운 동선이라서. 새 단원 탐색용 진입은 두지
않는다.

관리자 지표(소단원 수, 성취도 점수)는 버리거나 월간 보고서(`util/report.html`)로
분담한다. 이 페이지는 **학생이 스스로 읽는 화면**이다.

## 3. 확정 구조 (골격)

위에서 아래로:

1. **주간 내비** — 달력+적용하기 폐기. 좌우 페이저로 주 단위 이동(+ 「이번 주」 복귀,
   달력 점프는 보조). 주 정의는 **달력 주(월~일)** — 롤링 7일은 "이번 주"라는 말과
   어긋난다.
2. **주간 요약** — 지표 6→4로 재편 (§5).
3. **4주 흐름** — 표 삭제. 그래프는 단일 지표 미니 막대 4개로 축소. (골격 시안 B에서는
   요약과 합쳐 히어로 하나가 된다.)
4. **기록 목록** — `[학습한 내용 | 날짜별]` 토글. 내용별이 기본.
   - **내용별**: 이번 주에 학습한 소단원 카드. 단, 카드 안의 진행 상태는 **누적**(단원의
     현재 상태)이고, 이번 주에 한 활동에만 하이라이트를 얹는다. → 문제 4의 답.
     "이번 주에 뭘 했나"와 "이 단원 어디까지 왔나"를 한 카드가 동시에 답한다.
   - **날짜별**: 타임라인. 날짜 그룹 아래 시각·훈련·라운드·소요시간·점수.
5. **결과 모달** — 세부 활동 표에 **이전 라운드 대비 증감 열** 추가. → 문제 5의 답.
6. **도움말 박스 삭제** — 규칙은 그 규칙이 적용되는 자리에 인라인으로 쓴다
   (예: 잠긴 라운드 칩에 "R1을 마치면 열려요"). → 문제 3의 답.

## 4. 확정 사양 (2026-08-24 사용자 채택 — 전 항목 추천안)

기호는 `tools/history-wire.html`과 같다. 탈락안(A 상단부·P1·N2)은 와이어에 참고로만 남아 있다.

- **골격 = B 성장 기록형.** 정답률 히어로(지난주 대비 문구 + 4주 스파크 합체) +
  서브 한 줄(훈련·시간·맞힌 문제·학습한 날). 단, **목록·토글 부분은 골격 A 조립본에
  그려진 그대로**다(B 시안은 상단부만 그렸고 "이하 A와 동일"이라 명시).
- **내용별 카드 = P2 훈련 우선.** 개념·유형·서술형 3열, 열 안에 라운드 칩이 세로로

- **기록 범위 = 현재 과목만**(GNB 과목 모드를 따라감). 학기는 전체.
- **등급 어휘 = 목록은 점수 숫자만.** 등급 배지는 결과 모달에서만. 왕관·번개 금지(원칙 18).

## 6. 데이터 모델 — 코딩 세션이 물어볼 것

훈련 기록 1건(두 목록이 공유하는 단위):

```
{ 과목, 학기, 대단원, 소단원, 훈련종류(개념|유형|서술형), 라운드(1~3),
  시작일시, 소요분, 정답수, 문제수,
  세부활동: [{이름(개념 학습|기초 연산|…), 정답수, 문제수}] }
```

파생 규칙(저장하지 않고 계산):
- 정답률 = 정답수/문제수. 등급 = S/A/B/C (컷은 스타일 단계에서 확정 — 현안 83=B만 확인됨).
- 훈련 상태: 완료(기록 있음+종료) / 진행중(기록 있음+미종료) / 시작 전(기록 없음).
- 라운드 N+1 잠김 해제 = 같은 훈련의 라운드 N 완료. 최대 3라운드.
- 소단원 결과(라운드 단위) 잠김 해제 = 그 라운드의 세 훈련 모두 완료.
- 증감 = 같은 훈련의 직전 라운드 같은 세부활동과 비교.
- 주간 요약 = 해당 주(월~일) 기록의 집계. 학습한 날 = distinct 날짜 수.
- 세부활동 구성은 훈련종류마다 다르다(개념: 개념 학습+기초 연산 — 2026-08 현재 수학
  기준 2스텝. 유형·서술형은 9-2·9-3 탐방에서 확인 예정 — **더미 데이터는 개념 훈련
  구성만 실측이고 나머지는 가정임을 주석으로 남길 것**).

## 7. 상태 규칙 (부가 케이스)

- **빈 주**: 섹션 제목·틀은 유지. 요약 자리에 "이 주에는 학습 기록이 없어요" 카드 +
  **「기록이 있는 마지막 주로」 버튼**. 목록 자리는 빈 상태 문구. 통째로 사라지는 현안
  방식 금지.
- **첫 사용(기록 0)**: 빈 주와 같되 이동 버튼 없이 "첫 훈련을 마치면 여기에 기록이
  쌓여요" + 홈으로 가는 링크 하나.
- **최대**: 긴 소단원명 줄바꿈(칩·카드가 밀리지 않게), 한 주에 소단원 3개+, 라운드 3개
  모두 완료, 하루에 훈련 5회+ 타임라인. 와이어프레임에 맥스 카드 1장 포함.
- **진행중만 있고 완료 0**: 요약의 맞힌 문제 칸은 진행중 것도 집계(현안과 동일 —
  30/36에 학습중인 유형 훈련 점수도 포함돼 있었음).
- 정적 프로토타입이므로 로딩·통신 실패 상태는 만들지 않는다(명시적 생략).
- 상태 검수는 debug-panel이 아니라 **`?state=` 주소 플래그**(empty|first|max)로 —
  이 화면은 학습 엔진이 없다.
