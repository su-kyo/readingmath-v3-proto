## 남은 과제 (2026-10-12 기준, `style-audit.py` 「지켜볼 것」)

- 화면 CSS가 1단 램프를 직접 부르는 곳 약 800곳 — 테마가 뒤집히는 색은 2단 역할로 옮긴다
- 화면 간 똑같은 규칙 405개 — 대부분 킵 화면 쌍(서술형 가로/세로 안)과 순서가 얽힌 규칙
- `.card` · `.qtab` · `.problem` — 화면마다 다른 부품인데 이름이 같다. 공용으로 올리기 전에 이름부터 가른다
