# 콘솔바 안내 · 개발자 추가분 받아오기 (2026-10-15)

테스트 서버(`test.readingmath.co.kr`)를 탐방하면서 개발자가 넣은 안내 문구와 학습 동작을 모았고, 그것을 디자인 시스템에 맞게 프로토타입으로 옮겼다.
규칙 번호는 `RM-PART-07`이다(정본 `styleguide/rules.html`).

## 결정 (사용자)

- 「채점하기 · 다음 문제」를 본문에서 콘솔바 오른쪽 CTA로 옮기는 개발자 방식을 받아들인다.
- 받아오는 범위는 안내와 학습 동작까지다. 확인 창(「해설 보기를 종료하실 거예요?」 등)과 훈련 완료 축하 화면은 개발자 것을 그대로 둔다.
- 안내 모양은 시안 넷(가운데 · CTA 옆 × 다크 알약 · 글자만) 중 **CTA 옆 · 글자만**으로 정했다.
  글자가 특정 트레이에서 안 보인다는 지적이 있어 보완했다. 글자는 남색 하나로 고정하고, 상태는 컬러 램프로만 말한다.
  다크 소켓(남색 테두리)은 어색하다는 의견이 있어 테두리도 상태색으로 바꿨다.
- 유형 해설 박스의 머리 이름은 「해설」로 한다(테스트 서버는 맞힌 문항에도 「오답 해설」).

## 근거 (수치)

트레이 대비(WCAG). 글자 `--guide-ink`(n-650)는 개념 7.3 · 유형 13.1 · 서술형 9.5다.
상태색 글자는 개념 트레이(#87AEEC)에서 초록 600이 2.75, 빨강 600이 3.23이라 쓰지 않는다.
램프 테두리 700은 개념 트레이에서 파랑 4.2 · 초록 4.0 · 빨강 4.5다.
콘솔 그림(SVG)과 트레이 색은 에셋 연동색(`RM-ASSET-05`)이라 바꾸지 않았다.

## 세션이 정한 것 (사용자 확인 전)

- 문구: 객관식 입력 전에는 「답을 골라 주세요!」를 쓴다(테스트 서버는 객관식도 「답안을 입력해 주세요!」). 칸이 여럿이면 「모든 답안을 입력해 주세요!」.
- 문구: 개념 학습 끝은 「다 읽었어요! 개념 요약하기 버튼을 눌러 주세요!」. 프로토 버튼 이름이 「개념 요약하기」라서 그렇다(테스트 서버는 「내용 요약해보기」).
- 문구: 서술형 순서 맞추기는 「블록을 눌러 알맞은 자리에 넣어 주세요!」. 프로토는 끌어다 놓기가 없어서 「끌어다 놓아」를 뺐다.
- 안내 최대 폭 18em. 넘으면 두 줄로 접힌다. 개념 학습 콘솔바(버튼 넷)에서 1280px에 겨우 들어가기 때문이다.
- 개념 학습 요약 버튼의 주의 애니메이션(테스트 서버)은 넣지 않았다. 모션 수치를 정한 적이 없다.
- 유형 풀이: 마지막 문제 전에는 「다음 문제」, 마지막 문제에서만 「제출하기」(테스트 서버는 모든 문제가 「제출하기」).
- 유형 해설: CTA는 「다음 문제」, 마지막만 「결과보기」(테스트 서버는 「다 읽었어요」). 해설에서 오답을 눌러 정답을 여는 동작을 넣었지만 「다음」을 잠그지는 않는다.
- 서술형 기본 다지기의 단계 버튼(「순서 맞추기」 · 「다음 문제」)은 본문 아래에 그대로 둔다. 원래 판단(「콘솔바 대신 콘텐츠 하단」)을 존중했다.
- 서술형 해설 2장의 본문 안내문(`.review-hint`)은 지우고 콘솔바 안내로 옮겼다.
- 타이머 말풍선은 풀이 중에만 붙는다(해설 · 결과의 정지 타이머에는 없다).
- 램프는 1.6초 주기로 깜빡인다(테스트 서버와 비슷하게). 움직임 줄이기 설정이면 멈춘다.
